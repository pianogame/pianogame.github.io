# ドリステのお知らせ配信

この news-feed ブランチはデータ配信専用です。main / staging にマージしないでください。Vercel の自動デプロイは無効です。

news.json のみ更新してください。アプリは起動時・ホーム表示時・アプリ復帰時・お知らせを開く時に取得します。端末には最後に取得した正常な内容を保存し、通信失敗時も表示します。

version は 1、items は最大100件です。各項目の id は重複させず、title、任意の tag、任意の body を記載します。改行は JSON の \n で指定します。HTMLは使わず通常の文字列を記載してください。項目の順番が表示順です。既読後も同じ id の内容を変更すると未読になります。items を空にするとお知らせ無しになります。
